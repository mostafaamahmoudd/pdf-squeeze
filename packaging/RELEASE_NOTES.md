## Downloads

- Windows x64: `pdf-squeeze-windows-x64.zip`
- Linux x64 (built on Ubuntu 22.04): `pdf-squeeze-linux-x64.tar.gz`
- macOS Apple Silicon: `pdf-squeeze-macos-arm64.zip`
- macOS Intel: `pdf-squeeze-macos-x64.zip`

Use `SHA256SUMS.txt` to check downloaded archives. Each archive contains installation instructions. Ghostscript is a separate required installation; see the [official Ghostscript downloads](https://ghostscript.com/releases/gsdnld.html). It is not included in these packages.

The Linux binary was built and checked on Ubuntu 22.04; compatibility with other distributions has not been established. The macOS app bundles are experimental, not Developer ID signed, and not notarized. Gatekeeper may block them. See each archive's `INSTALL.md` before use.
